webserv

a tiny HTTP server, written in C++98 for the 42 project

Static content

  • /style.css - this stylesheet
  • /hello.txt - a plain text file
  • /files/ - directory listing (autoindex)

HTTP methods

  • GET: served everywhere
  • POST: upload a file at /upload (stored in www/upload/)
  • DELETE: remove an uploaded file, e.g. DELETE /upload/hello.txt

CGI

  • /cgi-bin/hello.py - python CGI (GET with query args)
  • /cgi-bin/env.sh - shell CGI printing the CGI environment

More features

  • /session - cookies and session management
  • /old - HTTP 301 redirect to /
  • /private/ - directory listing forbidden (403)
  • /missing-page - custom 404 error page
  • http://127.0.0.1:8081/ - second server block on another port
